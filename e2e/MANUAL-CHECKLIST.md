# 发版前手动清单

先跑 `npm run preflight`（全部通过、没有跳过），再过这份清单。条目按**代码**整理
（`src-tauri/src/main.rs` 的命令表、`features/settings/components/groups/` 的设置项），
不是按文档站。只列自动化测不到的：系统级交互、真实外部服务、平台原生行为。

## 已自动化，不用手点

- **UI e2e**（`e2e/tests/app.e2e.ts`）：搜索、分类筛选、单击/键盘/详情栏粘贴请求、删除、
  清空确认、设置分组与保存、标签筛选、固定、新记录插入位置、紧凑模式、表情包与互传视图、崩溃兜底
- **Rust 单测**：隐私识别（URL/手机/邮箱/自定义正则）、复制规则（替换/不记录）与按应用匹配、
  富文本/表格/WPS/Office 转换、搜索匹配、Ditto/Maccy 导入解析、加密、数据库迁移、云同步与互传协议
- **原生 smoke**（macOS）：app 启动、建库、重启后读设置、捕获一次复制
- **文档站**：全部页面生成、链接与锚点、核心交互

## A. 每次发版必过（两个平台各一遍，约 10 分钟）

- [ ] 打开窗口快捷键：在别的应用里呼出 / 隐藏
- [ ] 在备忘录 / 记事本里选一条记录粘贴，内容真的粘进去
- [ ] 带格式粘贴快捷键、纯文本粘贴快捷键各一次：网页复制的带格式文字，前者保留格式、后者不保留
- [ ] 从网页、Excel、Finder/资源管理器 各复制一次（文字、表格、图片、文件），都进历史且来源应用名正确
- [ ] 顺序粘贴：开启后连续复制 3 条，在目标应用里按顺序逐条粘出
- [ ] 数字粘贴（快速粘贴修饰键 + 数字）粘出对应条目
- [ ] 复制一个密码管理器里的密码，不进历史（标记为私密的内容会被丢弃）
- [ ] 托盘菜单能打开、退出；深色 / 浅色切换后界面颜色正确（预览 harness 测不了）
- [ ] 从上一个正式版升级安装：历史、设置、标签、固定顺序都还在
- [ ] 全新安装首次启动（从「应用程序」/ 安装目录启动）：开机自启已开启，设置页显示为开；升级安装不改动原有的开机自启状态

## B. 改到这些代码时才测

| 改了 | 测什么 |
| --- | --- |
| `services/cloud_sync.rs` | 两台设备 WebDAV 互相同步一条文字、一张图片；开启"表情收藏"同步后收藏也同步 |
| `services/mqtt_sub.rs`、`services/e2e.rs`、`E2eKeyPanel.tsx` | 验证码同步：手机发一条到电脑。**再开启端到端加密测一次**：开启后未加密消息会被静默丢弃，短信转发类第三方工具会收不到；手机扫配置二维码后密钥一致 |
| `services/file_transfer/` | 局域网互传：手机扫码连接，双向发文字和文件；"自动复制""自动打开"生效；约 5 分钟无传输自动关闭 |
| `commands/ai_cmd.rs`、`ai_provider.rs`、`AiSettingsGroup.tsx` | 用真实模型"检查连接"，对一条记录做一次解答 / 翻译 |
| `services/importers/` | 从 Ditto（Windows）或 Maccy（macOS）导入：自动找到记录文件，重复项跳过，原文件不变 |
| `set_data_path`（`commands/system_cmd.rs`） | 数据管理里更换数据位置：迁移后历史完整，重启后仍用新位置。**先备份数据** |
| `infrastructure/encryption.rs`、`repository/migrations.rs` | 用旧版本数据目录启动新版本，历史全部可读、可搜索 |
| `app/light_mode.rs` | 开启"节省内存"，把等待时间调到最短，等它释放后再呼出：窗口能恢复，监听和快捷键一直有效 |
| `commands/hotkey_cmd.rs` | 改一个快捷键为已被占用的组合，提示冲突；改成新组合后立即生效 |
| `commands/theme_cmd.rs` | 从主题商店安装、切换、卸载一个主题 |
| `commands/update_cmd.rs` | 旧版本能检测到新版本并完成更新（stable 和 beta 通道各看一次） |
| 贴图 / 紧凑预览窗口相关 | 图片贴图能钉在最前、能关闭；紧凑模式下悬停预览正常弹出和消失 |
| 设置"打开方式" | 给某类内容指定应用后，"打开"用的是那个应用 |
| 设置"复制规则" | 对某个应用设"不记录"，从该应用复制不进历史；其他应用不受影响 |

## C. 平台专属

**macOS**
- [ ] 全新安装：辅助功能授权提示出现；授权后粘贴生效；撤销授权后不会卡住系统输入
- [ ] 未授权辅助功能时单击一条记录：弹出授权提示，**内容仍已复制**，手动按 ⌘V 能粘出这一条

- [ ] 开机启动：开启后注销重登确认自动运行（大版本才测）

**便携版**（`--features portable`：数据**不加密**、搜索走另一套 SQL 实现）
- [ ] 启动后 data 目录在 exe 旁边
- [ ] 复制几条后搜索能搜到（便携版搜索代码路径和安装版不同，单测和 e2e 都没覆盖）
- [ ] 用新版 exe 替换旧版，data 里的历史保留
